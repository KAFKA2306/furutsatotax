# 基礎控除（所得税・住民税）

基礎控除は所得税と住民税で金額が異なり、さらに所得税側は2025年分・2026年分で改正されています。**「現行は一律48万円」として扱ってはいけません。**

## 所得税

### 2024年分

合計所得金額2,400万円以下の一般ケースは48万円です。2,400万円超では32万円、16万円、0円へ逓減します。

### 2025年分

令和7年度税制改正により、合計所得金額に応じて次の特例があります。

| 合計所得金額 | 基礎控除 |
|---:|---:|
| 132万円以下 | 95万円 |
| 132万円超336万円以下 | 88万円 |
| 336万円超489万円以下 | 68万円 |
| 489万円超655万円以下 | 63万円 |
| 655万円超2,350万円以下 | 58万円 |

2,350万円超の高所得帯は従来の逓減区分が続きます。

### 2026年分

令和8年度税制改正により、一般的な所得帯でも2025年分と金額が異なります。本ツールは年度別の表を実装し、別年度の金額を流用しません。

## 住民税

住民税の基礎控除は、令和8年度・令和9年度の税制改正でも所得税と同じ増額にはなっていません。一般的な合計所得2,400万円以下では43万円で、高所得帯は29万円、15万円、0円へ逓減します。

## ふるさと納税との関係

令和8年度住民税（2025年分所得）以降は、特例控除率の判定で

```text
max(所得税の基礎控除額 - 48万円, 0)
```

を課税総所得金額等から差し引くため、所得税基礎控除の年度差がふるさと納税上限にも影響します。
