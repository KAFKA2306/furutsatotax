# 配偶者控除・扶養控除（概要）

配偶者控除・扶養控除は、対象者の所得、年齢、納税者本人の所得、年度によって要件が変わります。ふるさと納税上限計算でこれらを一律の金額として自動推定すると誤差が大きくなるため、本ツールでは実際の住民税控除額または人的控除額の差を入力する設計にしています。

## 2025年分所得・令和8年度住民税

令和8年度から、配偶者控除・扶養控除の対象となる親族等の所得要件は、合計所得金額48万円以下から**58万円以下**へ引き上げられました。給与収入のみの場合の目安は103万円以下から**123万円以下**へ変わっています。

したがって、旧来の

```text
配偶者給与103万円以下 → 配偶者控除38万円
```

という単純判定を2025年分以降へ流用してはいけません。

さらに、実際の控除額は次の要因で変わります。

- 納税者本人の合計所得金額
- 配偶者の合計所得金額
- 配偶者控除か配偶者特別控除か
- 一般配偶者・老人配偶者
- 扶養親族の年齢区分
- 所得税と住民税の控除額差
- 税年度

## 2026年分所得・令和9年度住民税

令和9年度住民税では所得要件がさらに改正されます。大阪市の公表資料では、令和9・10年度の配偶者控除・扶養控除の所得要件は合計所得62万円以下、給与収入のみの場合は136万円以下とされています。

## ふるさと納税との関係

ふるさと納税の特例控除率や調整控除では、所得税と住民税の**人的控除額の差**が使われます。基礎控除だけの単純ケースでは5万円ですが、配偶者・扶養・障がい者等がある場合は差額を追加する必要があります。

公開計算機は、この人的控除差をユーザーが確認して入力する方式に変更し、配偶者年収だけから自動決定しません。
