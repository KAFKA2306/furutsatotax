# 所得税の基本

所得税は超過累進税率（5%〜45%）で計算します。課税所得は1,000円未満を切り捨て、速算表の区分を適用します。

## 税率区分

| 課税所得 | 税率 | 控除額 |
|---:|---:|---:|
| 1,000円〜1,949,000円 | 5% | 0円 |
| 1,950,000円〜3,299,000円 | 10% | 97,500円 |
| 3,300,000円〜6,949,000円 | 20% | 427,500円 |
| 6,950,000円〜8,999,000円 | 23% | 636,000円 |
| 9,000,000円〜17,999,000円 | 33% | 1,536,000円 |
| 18,000,000円〜39,999,000円 | 40% | 2,796,000円 |
| 40,000,000円以上 | 45% | 4,796,000円 |

境界値そのものは上の新しい区分に入ります。たとえば課税所得3,300,000円は20%、6,950,000円は23%です。

## 2025年・2026年は基礎控除が年度別

2025年分以降は所得税の基礎控除が改正されているため、2024年分の48万円を固定で流用しません。詳細は[基礎控除](基礎控除.md)を参照してください。

## ふるさと納税上限との関係

所得税の限界税率だけからふるさと納税上限を決めるのは不十分です。

令和8年度住民税（2025年分所得）以降、住民税特例控除率の通常ケースでは、

```text
課税総所得金額
- 所得税との人的控除額の差
- max(所得税基礎控除額 - 48万円, 0)
```

に応じた住民税側の公式割合を使います。このため、本ツールの正準モードは所得税率からの単純逆算ではなく、住民税通知書と公式特例控除率表を使います。

## 復興特別所得税

ふるさと納税の住民税特例控除率は、復興特別所得税による所得税側の軽減も考慮した割合（例: 69.58%、66.517%）になっています。
