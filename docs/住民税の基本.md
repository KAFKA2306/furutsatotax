# 住民税の基本

個人住民税は前年の所得を基礎として翌年度に課税され、主に所得割・均等割等から構成されます。

ふるさと納税上限計算では、単に「課税所得×10%」を見るだけでは不十分です。**所得割のどの段階の金額を使うか**を区別する必要があります。

## 所得割の流れ

一般的な標準税率のイメージは次です。

```text
課税標準
  ↓ 税率
税額控除前所得割額（算出所得割額）
  ↓ 調整控除
調整控除後所得割額
  ↓ 寄附金・住宅ローン・配当・外国税額等の税額控除
最終的な所得割額
```

## ふるさと納税で使う金額

ふるさと納税特例分の20%上限は、**調整控除後所得割額**を基礎にします。

```text
調整控除後所得割額
= 税額控除前所得割額 - 調整控除額

特例控除上限
= 調整控除後所得割額 × 20%
```

したがって、寄附金税額控除などを差し引いた後の最終所得割額を20%上限の母数にすると、すでに受けたふるさと納税控除を二重に差し引くことになり、上限を過小評価します。

## 調整控除

大阪市の通常ケースでは、合計課税所得金額が200万円超の場合、人的控除額の差と課税所得に基づいて計算し、計算結果の基礎額が5万円未満なら5万円として、市民税4%・府民税1%の計5%を乗じます。

ただし、実際の住民税通知書がある場合、本ツールは調整控除を推定せず**通知書記載の実額を優先**します。

## 年度対応

- 2025年分所得 → 令和8年度住民税
- 2026年分所得 → 令和9年度住民税

給与所得控除や扶養親族等の所得要件は年度ごとに改正されているため、別年度の数値を流用しません。
