# 税制ガイド

このサイトは、ふるさと納税の上限計算と、企業型DC・iDeCo・小規模企業共済などの関連制度を整理します。

## ふるさと納税の計算は通知書実額を優先

上限計算で最も重要なのは、住民税の「最終所得割額」ではなく、**税額控除前所得割額から調整控除を差し引いた額**です。

```text
調整控除後所得割額
= 税額控除前所得割額 - 調整控除額

特例控除の20%上限
= 調整控除後所得割額 × 20%

寄附上限
= 特例控除の20%上限 ÷ 特例控除率 + 2,000円
```

令和8年度住民税（2025年分所得）以降の通常ケースでは、特例控除率の判定基礎は次のとおりです。

```text
課税総所得金額
- 所得税との人的控除額の差
- max(所得税の基礎控除額 - 48万円, 0)
```

株式等の分離課税、課税山林所得、課税退職所得、その他の課税特例がある場合は通常表と異なる割合が適用されるため、公開計算機は通常表で勝手に確定せず、確認済みの特例控除率がなければ停止します。

## 信頼度の順序

1. **住民税通知書モード**: 税額控除前所得割額・調整控除額などの実額を使用。
2. **収入からの概算**: 単純な総合課税ケース向け。分離課税がある場合はfail-close。
3. **年収だけの早見**: 本リポジトリでは正準上限として扱わない。
