# 寄附金控除・寄附金税額控除（ふるさと納税）

ふるさと納税では、一定の上限内で、寄附額のうち2,000円を超える部分が所得税と個人住民税で軽減されます。

## 控除の構造

確定申告をする場合の基本構造は次の3つです。

1. 所得税・復興特別所得税の寄附金控除
2. 住民税の基本分
3. 住民税の特例分

住民税基本分は原則として、対象となる寄附額から2,000円を差し引いた額の10%です。対象寄附金には総所得金額等の30%という上限があります。

## ふるさと納税上限で最重要の20%ルール

住民税の特例分には、**市民税・府県民税の所得割額のうち「調整控除額控除後の額」の20%**という上限があります。

したがって、通知書を使う場合の正準計算は次です。

```text
調整控除後所得割額
= 税額控除前所得割額 - 調整控除額

特例控除上限
= 調整控除後所得割額 × 20%

ふるさと納税上限
= 特例控除上限 ÷ 特例控除率 + 2,000円
```

**寄附金税額控除や住宅ローン控除などを差し引いた後の「最終所得割額」を20%上限の母数にしてはいけません。**

## 特例控除率

平成26年度から令和20年度まで、復興特別所得税を考慮した通常ケースの率は次です。

| 判定基礎 | 特例控除率 |
|---:|---:|
| 195万円以下 | 84.895% |
| 195万円超330万円以下 | 79.790% |
| 330万円超695万円以下 | 69.580% |
| 695万円超900万円以下 | 66.517% |
| 900万円超1,800万円以下 | 56.307% |
| 1,800万円超4,000万円以下 | 49.160% |
| 4,000万円超 | 44.055% |

令和8年度住民税（2025年分所得）以降、通常ケースの判定基礎は次のように算定します。

```text
課税総所得金額
- 所得税との人的控除額の差
- max(所得税の基礎控除額 - 48万円, 0)
```

このため、所得税の「限界税率」だけを見て `90% - 所得税率×1.021` と機械的に逆算すると、令和8年度以降の基礎控除改正や個別の課税区分を取りこぼす場合があります。本ツールは住民税側の公式表を正準とします。

## 分離課税等がある場合

大阪市公式は、次のような所得がある場合には通常表と異なる割合が適用されると明記しています。

- 課税山林所得
- 課税退職所得
- 土地建物・株式等を含む課税の特例が適用される所得

この場合、通知書の「税額控除前所得割額」を使えば20%上限の母数は実額化できますが、**特例控除率そのものを通常表から断定しません。** 公開計算機では、確認済みの率を入力しない限りfail-closeします。

## ワンストップ特例

確定申告をした場合、ワンストップ特例は適用されません。寄附金控除を受けるふるさと納税を確定申告へまとめて記載する必要があります。
