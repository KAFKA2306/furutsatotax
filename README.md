# ふるさと納税 上限目安計算ツール

**公開サイト:** https://kafka2306.github.io/furutsatotax/

給与、副業、事業所得、社会保険料、企業型DC、iDeCoなどの入力から、ふるさと納税の自己負担2,000円に収まる寄附額を概算する研究用ツールです。

## 重要：2025年分以後の計算には未対応

現在の`scripts/calc_furusato.py`は、次の古い値を固定しています。

- 給与所得控除の最低額: 55万円
- 所得税の基礎控除: 合計所得2,400万円以下で48万円

国税庁の令和7年分資料では、給与所得控除の最低額は65万円へ変更され、所得税の基礎控除も合計所得に応じて95万円、88万円、68万円、63万円、58万円などへ見直されています。

- 国税庁「給与所得控除とは（令和7年分以後）」  
  https://www.keisan.nta.go.jp/r7yokuaru_sp/cat2/cat21/cat213/scid090.html
- 国税庁「基礎控除とは（令和7年分）」  
  https://www.keisan.nta.go.jp/r7yokuaru/cat2/cat22/cat22c/cid065.html
- 国税庁「令和7年度税制改正による所得税の基礎控除の見直し等」  
  https://www.nta.go.jp/users/gensen/2025kiso/index/shinkoku.htm

`scripts/calc_furusato.py`の`tax_year`引数は、現時点では控除表を年度別に切り替えていません。**2025年分・2026年分の確定申告や寄附判断に、現在の計算結果を使用しないでください。**

## 現在コードが行う概算

```text
給与収入
  → 給与所得控除を差し引く
副業・事業・投資の入力
  → 簡易的に合計所得を計算
所得控除
  → 所得税・住民税の課税所得を計算
住民税所得割
  → 特例控除20%を使った近似式
  → 2,000円を加えて上限目安を算出
```

近似式:

```text
(住民税所得割額 × 20%)
÷ (90% − 所得税率 × 1.021)
+ 2,000円
```

この式は一般的な目安計算であり、実際の住民税所得割額と各種税額控除を完全には再現しません。

## 所得税率

所得税の速算表は、課税所得に応じた5%〜45%の7段階です。復興特別所得税は、原則として基準所得税額の2.1%です。

- 国税庁「No.2260 所得税の税率」  
  https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/2260.htm

現在のコードは所得税額の表示に復興特別所得税を加算していませんが、ふるさと納税近似式の分母では`1.021`を使用しています。

## 現在考慮している入力

- 給与収入
- 副業収入と経費率
- 事業収入・事業経費
- 青色申告特別控除の簡易選択
- 投資差益の入力
- 社会保険料
- 企業型DCマッチング拠出
- iDeCo
- 小規模企業共済
- 基礎控除の手動上書き

## 未対応または簡略化している項目

- 年度別の給与所得控除・基礎控除
- 復興特別所得税の税額表示
- 住民税の調整控除
- 住民税均等割・森林環境税
- 配偶者控除、扶養控除、特定親族特別控除
- 医療費控除、生命保険料控除、地震保険料控除
- 住宅ローン控除
- 配当控除、外国税額控除
- 株式・先物・暗号資産などの所得区分
- 損益通算と繰越控除
- 事業所得と雑所得の判定
- 自治体ごとの差異
- ワンストップ特例と確定申告の差異

`capital_gains`は単純に合計所得へ加算されるため、申告分離課税の上場株式等を正しく扱いません。

## 実行方法

```bash
python scripts/calc_furusato.py input.yaml --tax-year 2024
```

現在の固定控除表に近い条件で使う場合も、入力年度、所得区分、控除、住民税通知書と照合してください。

入力例:

```yaml
tax_year: 2024
salary_income: 6000000
side_income: 300000
expense_rate: 0.2
social_insurance: 900000
ideco: 276000
business_revenue: 0
business_expenses: 0
capital_gains: 0
```

## 改修が必要な箇所

### `salary_income_after_deduction`

年度別の給与所得控除表へ分岐させる必要があります。

### `basic_deduction_income_tax`

令和7年分の所得税基礎控除表を実装し、制度上の適用年・経過措置を明示する必要があります。

### `basic_deduction_resident_tax`

個人住民税は所得税と適用年度が異なる可能性があるため、所得税の年分と住民税の年度を別パラメータにする必要があります。

### テスト

国税庁の計算例、源泉徴収票、住民税通知書を使った年度別回帰テストが必要です。

## 利用上の注意

- 上限額は「収入」だけでは決まりません
- 住民税決定通知書の所得割額と各種控除を確認してください
- 年末までに所得や控除が変わると上限も変わります
- 安全余裕を持たず上限ぴったりまで寄附すると、自己負担が2,000円を超える可能性があります
- 正確な申告は税務署、自治体、税理士または国税庁の作成コーナーで確認してください

本ツールは税務助言ではありません。
