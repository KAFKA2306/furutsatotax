# ふるさと納税 上限目安計算ツール

**公開サイト:** https://kafka2306.github.io/furutsatotax/

**同じ給与収入でも、2024年・2025年・2026年では「給与所得」が同じとは限らない。**

ふるさと納税の上限目安を考えるとき、収入額だけでなく「どの年分の税制で計算するか」も結果を左右します。このツールは、給与、副業、事業所得、所得控除などから概算上限を計算し、対応していない年度は別年度の表を流用せずエラーで停止します。税務申告ソフトや自治体計算を代替しません。

## 対応年度

`scripts/calc_furusato.py`は、所得税の年分を明示して次の表を切り替えます。

| `tax_year` | 給与所得控除 | 所得税の基礎控除 |
|---:|---|---|
| 2024 | 令和2〜6年分の表 | 48万・32万・16万・0円 |
| 2025 | 最低保障65万円を含む令和7年分 | 95万〜58万円の所得帯別特例と高所得帯逓減 |
| 2026 | 最低保障74万円と低所得帯の年末調整表 | 104万・67万・62万円と高所得帯逓減 |

未実装年度は別年度の表を流用せず、エラーで停止します。

公式資料:

- 国税庁「令和7年度税制改正による所得税の基礎控除の見直し等」  
  https://www.nta.go.jp/users/gensen/2025kiso/index/shinkoku.htm
- 国税庁「令和8年度税制改正による所得税の基礎控除の見直し等」  
  https://www.nta.go.jp/users/gensen/2026kiso/index.htm
- 国税庁「No.2260 所得税の税率」  
  https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/2260.htm

## 監査で修正した問題

- `tax_year`を受け取るだけで控除表へ反映していなかった処理を年度別実装へ変更
- 2025年・2026年改正後の給与所得控除と所得税基礎控除を追加
- 未対応年度を黙って計算する挙動を禁止
- 所得税の課税標準を1,000円未満切捨てへ変更
- `expense_rate`を0〜1へ制限
- NaN・無限大・負値などの不正入力を拒否
- 上場株式等にも使われ得る`capital_gains`を無条件で総合課税へ加算する挙動を禁止
- 企業型DCマッチング拠出を一般上限から推定した場合は警告を表示
- 年度別回帰テストを追加

## 実行

```bash
python scripts/calc_furusato.py input.yaml --tax-year 2026
```

入力例:

```yaml
tax_year: 2026
salary_income: 6000000
side_income: 300000
expense_rate: 0.2
social_insurance: 900000
ideco: 276000
business_revenue: 0
business_expenses: 0
capital_gains: 0
```

`capital_gains`を入力する場合、本当に総合課税へ含める所得だけであることを確認し、明示的に指定します。

```yaml
capital_gains: 100000
treat_capital_gains_as_aggregate_income: true
```

上場株式等の申告分離課税をこの指定で総合課税へ変換してはいけません。

## 計算の概要

```text
給与収入
  → 年度別の給与所得控除
副業・事業所得
  → 経費・青色申告特別控除の簡易反映
所得控除
  → 所得税・住民税の課税所得を概算
住民税所得割
  → 特例控除20%を用いる近似式
  → 自己負担2,000円を加えた上限目安
```

近似式:

```text
(住民税所得割額 × 20%)
÷ (90% − 所得税率 × 1.021)
+ 2,000円
```

## 重要な限界

次の事項は未対応または簡略化しています。

- 住民税の年度と所得税の年分の厳密な対応
- 住民税調整控除、均等割、森林環境税
- 復興特別所得税を含む最終所得税額表示
- 配偶者・扶養・特定親族・医療費・生命保険料・住宅ローン等の控除
- 配当、株式、先物、暗号資産などの所得区分と損益通算
- 事業所得・雑所得の法的判定
- 自治体ごとの差異
- ワンストップ特例と確定申告の差異
- 実際の住民税決定通知書との照合

したがって、計算結果は寄附判断の上限値ではなく、追加確認が必要な概算値です。

## テスト

```bash
python -m unittest discover -s tests -v
```

主な回帰条件:

- 同じ給与収入でも2024・2025・2026年で給与所得が変わる
- 2025年・2026年の所得税基礎控除帯
- 2026年の低所得給与帯
- 未対応年度、安全でない投資差益、範囲外経費率の拒否
- 所得税課税標準の1,000円未満切捨て

## 利用上の注意

- 寄附上限は収入だけでは決まりません
- 住民税決定通知書、源泉徴収票、各種控除を照合してください
- 上限ぴったりではなく安全余裕を持ってください
- 正確な申告は国税庁の作成コーナー、税務署、自治体、税理士へ確認してください

本ツールは税務助言ではありません。
